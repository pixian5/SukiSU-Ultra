RULE 1  GitHub Release assets are the ONLY trusted source.
        https://github.com/pixian5/SukiSU-Ultra/releases
        Every release carries SHA256SUMS.txt. Verify before flashing.
        GitCode mirror (https://gitcode.com/laotongtian/SukiSU-Ultra/releases)
        has the same assets but its attachments need a login to download.

RULE 2  DO NOT use the fixed object name
        cst:xbz/camellian/boot-sukisu-susfs-lto-stockdtb.img
        as "the latest image". Several cloud boxes wrote to this same name
        in parallel on 2026-11-08, producing at least three different
        kernels in 16 minutes. A filename is not a version.

RULE 3  Never flash an image without a checksum AND a matching document.
