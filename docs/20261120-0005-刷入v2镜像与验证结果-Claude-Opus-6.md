## 五、Shell 的授权说明

刷机重启后，`adb shell su` 不再可用。原因不是内核问题，而是 Shell 的授权之前是**临时租约**，重启后按设计失效。需要 root 操作时，在管理器里再给 Shell 授权一次即可；不影响任何 APP 的授权。

## 七、尚未完成的部分

1. **管理器 JNI 修复未生效**（`jni.cc:166` 补包名），需要重编管理器 APK；因此新应用首次授权时，记录包名可能仍为空——但 v2 内核会跳过空包名，不会删，功能可用；
2. 新应用的「首次授权不再报错」由 v2 的 `do_get_app_profile` 回退修复覆盖，可在实际授权时确认；
3. SuSFS 的隐藏能力尚未做真机效果验证（Momo / Play Integrity 等），本次只确认开机与授权正常。
