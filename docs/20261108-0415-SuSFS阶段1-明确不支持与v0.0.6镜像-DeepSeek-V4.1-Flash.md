# SuSFS 阶段 1：把「假支持」改成明确不支持（v0.0.6）

> 时间：2026-11-08 04:15（GMT+8）
> 依据：[SuSFS 镜像的修改建议](./20261108-0335-SuSFS镜像修改建议-Claude-Opus-6.md) 第 4 节「阶段 1」
> 结论：四条没有内核实现的命令已改为显式返回 `-EOPNOTSUPP`；用出厂配置 + LTO/CFI 重新编译并打包，产物 10/10 结构校验通过，已发布 v0.0.6。
> 本轮只做编译与发布，**没有刷机、没有碰手机**。
>

## 0. 一句话结论

以前管理器里 `sus_map`、`avc_log_spoofing`、`priority_uid_filter`、`sus_path_loop` 会「看起来支持、实际不生效」；现在这四条命令一进来就写回 `-EOPNOTSUPP`，管理器会明确报失败，`sus_map` 也不再出现在启用特性列表里。内核核心逻辑、`KALLSYMS_ALL`、`MIHW` 均未改动。

---

## 1. 改动明细

只改了 ABI 层 [susfs_abi.c](../tools/camellian-susfs/kernel/fs/susfs_abi.c)：

| 命令 | 改前 | 改后 |
| --- | --- | --- |
| `sus_path_loop` | 静默降级为一次性 `sus_path` | 直接写回 `-EOPNOTSUPP`，不做任何添加 |
| `sus_map` | 只给 inode 打标记，没有 maps 过滤钩子 | 直接写回 `-EOPNOTSUPP`，并从 `enabled_features` 移除 |
| `avc_log_spoofing` | 只记录开关变量，没有 selinux 钩子 | 直接写回 `-EOPNOTSUPP` |
| `priority_uid_filter` | 只打印日志，不参与判定 | 直接写回 `-EOPNOTSUPP` |

实现方式：统一的 `susfs_reject_cmd()`，按「结构体最后一个字段是 `int err`」的 ABI 约定，把 `-EOPNOTSUPP` 写到 `offset = sizeof(struct) - sizeof(int)`。

### 为什么不用 126

本 ABI 里 `126`（`ERR_CMD_NOT_SUPPORTED`）被用户态 `ksud` 当成「可忽略的不支持」静默放行，返回值仍是 `Ok`——正是要消除的假支持。因此用 `-95`（`-EOPNOTSUPP`），`ksud` 会把它转成错误，管理器明确提示失败。

### 未改动

- 内核核心 `fs/susfs.c`、文件系统钩子、`sus_path` / `sus_mount` / `sus_kstat` / `uname` / `cmdline` / `open_redirect` 全部原样。
- `CONFIG_KALLSYMS_ALL=y` 保持。
- `CONFIG_MIHW=n` 保持。
- `VERSION` 文件为 `0.0.6`（v0.0.5 已被 1.4.2 路线占用，本轮顺延）。

## 4. 与 v0.0.4 的行为差异

| 场景 | v0.0.4 | v0.0.6 |
| --- | --- | --- |
| 管理器添加 `sus_map` | 显示成功，实际不隐藏 | 明确失败；特性页不再标为启用 |
| 开启 `avc_log_spoofing` | 显示成功，实际无效果 | 明确失败 |
| 设置 `priority_uid_filter` | 显示成功，实际无效果 | 明确失败 |
| 添加循环隐藏路径 | 成功，但只隐藏一次 | 明确失败（请改用普通 `sus_path`） |
| `sus_path` / `sus_mount` / `sus_kstat` 等 | 可用 | 不变 |

## 5. 真机验证清单（由持有手机的机器执行）

1. 能开机、无重启循环；超过 3 分钟无反应视为失败。
2. 管理器显示「工作中」，授权可用。
3. 进程列表有 `com.sukisu.ultra:root:0`。
4. `ksud susfs status` 报 `v2.3.0 / NON-GKI`。
5. 管理器 SuSFS 特性页：`sus_map` 不应再显示为启用。
6. 操作 `sus_map` / `priority_uid_filter` / `avc_log_spoofing` / 循环路径时，应看到明确失败提示。
7. Momo 复测：记录「找到 Magisk / Zygisk / 代码注入」哪几项变化。
8. **不要**用 `adb shell su` 判断成败（调试模式关闭时本来不可用）。
