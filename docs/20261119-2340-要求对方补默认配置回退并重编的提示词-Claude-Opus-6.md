# 要求对方补「默认配置回退」并重编的提示词

- 时间：2026-11-19 23:40（GMT+8）
- 背景：对方编的 `boot-sukisu-susfs-allowlist-fix.img` 已确认包含「空包名跳过」修复，但它用的 `builtin` commit `4bec532dd` 缺 `do_get_app_profile` 的默认配置回退，新应用首次授权会报「更新 app profile 失败」
- 目标：让对方补上回退逻辑，重编 `-v2` 镜像，两个问题一起解决

---

## 提示词（可直接复制）

```
你上一版 boot-sukisu-susfs-allowlist-fix.img 的空包名跳过修复已确认生效（反汇编能对上），但还缺一处，会导致「给新应用首次授权时报更新 app profile 失败」。

原因：你用的 builtin commit 4bec532dd 里，do_get_app_profile() 在应用没有配置时返回 -ENOENT，管理器把它当成失败。需要改成返回一份默认的非 root 配置。

请做以下修改并重编：

1. 打开 kernel/supercall/dispatch.c，把 do_get_app_profile() 的
       if (!profile) {
           ret = -ENOENT;
       } else {
           ...
       }
   改成：
       if (!profile) {
           // 返回默认非 root 配置，避免管理器把 -ENOENT 当成失败
           struct app_profile fallback;
           memset(&fallback, 0, sizeof(fallback));
           fallback.version = KSU_APP_PROFILE_VER;
           fallback.curr_uid = uid;
           fallback.allow_su = false;
           fallback.nrp_config.use_default = true;
           fallback.nrp_config.profile.umount_modules = true;
           if (copy_to_user((char __user *)arg + offsetof(struct ksu_get_app_profile_cmd, profile),
                            &fallback, sizeof(fallback))) {
               pr_err("get_app_profile: copy_to_user default failed\n");
               ret = -EFAULT;
           }
       } else {
           if (copy_to_user((char __user *)arg + offsetof(struct ksu_get_app_profile_cmd, profile),
                            profile, sizeof(struct app_profile))) {
               pr_err("get_app_profile: copy_to_user failed\n");
               ret = -EFAULT;
           }
           ksu_put_app_profile(profile);
       }
   （union 字段名以你源码里的实际定义为准，app_profile 版本是 4。）

2. 确认上一版的核心修复仍在，不要回退：
   kernel/policy/allowlist.c 的 ksu_prune_allowlist() 里要有
       if (np->profile.key[0] == '\0') {
           continue;
       }

3. 重新全量编译（改了 .c 会触发 LTO 链接），确认返回 0、无 error。

4. 重新打包，输出文件名用 boot-sukisu-susfs-allowlist-fix-v2.img，
   不要覆盖 S3 上的旧文件；12 项结构校验必须全过。

5. 上传后用 SHA256 复核一次，报告：
   - 本次 diff（dispatch.c 的改动）
   - 编译命令、clang/LLD 版本、完成时间
   - 镜像大小、MD5、SHA256
   - 12 项结构校验结果

6. 不要刷机、不要连接手机、不要发布到主线 Release。

补充说明：这个回退返回的配置包名为空，这是内核侧拿不到包名的固有限制；但因为第 2 条的「空包名跳过」已经在，不会因此再被清理。管理器以后重新保存时会写成带包名的记录（需要管理器侧 JNI 修复才彻底，那是 APK 的事，不在本次范围）。
```

## 收到 v2 后的验收清单

1. SHA256 与对方给的一致；
2. 64 MiB、header v2、kernel/ramdisk/dtb/vbmeta/AVB 结构正常；
3. 反汇编或源码确认两处都在：`key[0] == '\0'` 跳过 + `do_get_app_profile` 回退；
4. 配置仍是 `CONFIG_KSU=y`、`CONFIG_KSU_SUSFS=y`、`KALLSYMS_ALL=y`、LTO/CFI 完整；
5. 再决定刷不刷（回退件 final3 始终保留）。
