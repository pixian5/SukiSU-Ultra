# 手机只读边界与刷机授权条件

> 撰写时间：2026-11-06 23:27（模型：Claude-Opus-6）
> 来源：用户明确要求「**在我明确说刷机之前，你不要修改我手机的数据。你可以只读**」。
> 效力：本项目最高优先的操作边界，覆盖本仓库后续所有会话，直到用户明确解除。

---

## 1. 这条边界解决什么问题

前面几轮已经在电脑上把内核编出来、把可刷的启动分区镜像打包好，并给出了「授权试刷」这个选项。用户随即把边界收紧：**镜像可以继续准备，但手机本身在明确说刷机之前，一个字节都不许改**。

这里把「只读」和「修改」逐项划清，避免以后出现「我只是重启一下读个变量」「我只是装个管理器应用」这类自作主张。

---

## 2. 允许：只读查询（不需要额外授权）

| 动作 | 说明 |
|------|------|
| 查看已连接的设备 | 例如列出 USB 调试设备，确认型号与连接状态 |
| 读系统属性 | 例如内核版本、系统版本、分区与槽位相关的只读属性 |
| 读只读文件 | 例如内核配置、进程列表、挂载列表，只看不写 |
| 读手机上已有的文件 | 读取内容用于分析，不改动、不删除、不新建 |
| 读刷机模式变量 | **前提是设备本来就处于刷机模式**；例如启动锁状态、槽位数量、当前槽、防回滚计数 |

> 术语说明：**刷机模式**（fastboot）是手机开机前的一个底层维护界面，可以读写分区；**USB 调试**（adb）是安卓系统运行起来后的调试通道。两者的「只读」都只取信息、不下写命令。

**电脑和云电脑一侧的工作完全不受这条约束**：编译内核、解包官方固件、打包镜像、下载、写文档、提交推送，都不碰手机，可以照常进行。唯一要求是**产物只准备、不刷入**。

---

## 3. 禁止：任何会改变手机状态的动作（在明确授权前一律不做）

| 类别 | 具体禁止的动作 |
|------|----------------|
| 写分区 | 刷启动分区或任何其它分区、擦除分区、写校验分区、刷动态分区 |
| 改槽位 | 切换当前系统槽、设置另一个槽为活动槽 |
| 重启 | 重启手机、**为了读变量而重启进刷机模式**、重启到恢复模式 |
| 传文件 / 装应用 | 推送任何文件到手机、安装或卸载应用（包括管理器应用与模块）、写入或删除手机上任何文件 |
| 执行脚本 | 官方线刷脚本、回锁启动锁的脚本、任何批量刷写脚本 |
| 其它 | 改系统设置、改属性、解锁或回锁启动锁、清除数据、恢复出厂 |

**特别说明「重启」**：上一轮为了读启动锁状态而重启进刷机模式，那次是用户单独说过「先做第四项把底摸清」才做的。现在这条边界生效后，**即使目的是为了读取只读信息，也不能先重启手机**——重启本身就改变了手机状态，需要单独授权。

**特别说明「装管理器应用」**：打包好的镜像即使将来刷进去，系统能开机也不会立刻获得 root，还需要装管理器应用。但装应用是往手机里写数据，同样在禁止之列，不能当作「收尾小动作」顺手做掉。

---

## 4. 什么才算「明确说刷机」

**算授权**：

- 用户明确说出「刷机」「刷进去」「开始刷」这类直接指令；
- 或明确点名授权某一个具体写操作，例如「可以重启进刷机模式读一下变量」「可以把原厂启动镜像刷回当前槽」。

**不算授权**（这些都已出现过，别误读）：

- 「继续」「下一步做什么」「三件事都做」——指的是文档、打包、资产整理，不包括动手机；
- 「分析」「检查一下」「实际检查一下」——只读动词；
- 我自己在回复里列出「选项 A／B／C」并推荐其中一个——**列选项不等于用户选了**；
- 用户没有回应，或者只回复了与手机无关的内容。

**授权范围只覆盖那一次、那一件具体的事**：授权「重启进刷机模式读变量」不代表可以顺手刷分区；这次刷完了不代表下次可以自动再刷。每次写手机都要重新确认。

---

## 5. 边界容易踩混的三种情况

1. **「准备」不等于「刷入」**：把镜像打包好、校验好、写好刷机命令清单，都属于电脑侧工作，允许；把命令真的执行到手机上，禁止。
2. **「只读命令」也可能带写副作用**：刷机模式里读变量的命令本身是只读的，但进入那个模式常常需要重启手机，所以整件事仍然禁止；除非手机已经自己处在那个模式。
3. **回退也算写手机**：万一将来真的授权试刷并且出了问题，「把原厂镜像刷回去」是回退手段，但它同样是写分区，属于**已授权那次试刷的配套动作**才可做；在没有授权的情况下，不能拿「我是为了救回来」当理由先动手。

---

## 6. 万一越界了怎么处理

立即停止所有手机侧操作，**不要试图自己补救或回滚**（补救本身是又一次写入）。如实报告：动了什么、什么时候动的、可能影响什么，然后等用户决定。不要隐瞒、不要轻描淡写。
